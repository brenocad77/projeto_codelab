# Ganesh - Website Oficial

Este repositório contém o código-fonte do website do **Ganesh**, um grupo extracurricular vinculado ao **ICMC - USP** (Instituto de Ciências Matemáticas e de Computação da Universidade de São Paulo) para o processo seletivo do grupo **CodeLab**.

---

## Sobre o Projeto

O projeto é uma aplicação web estática (HTML, CSS e JavaScript) desenvolvida para apresentar as informações sobre o Ganesh, seu processo de ingresso e suas atividades.

## Tecnologias Utilizadas

- **HTML5**: Estruturação semântica de todas as páginas.
- **CSS3**: Estilização modularizada por seções/páginas.
- **JavaScript (Vanilla)**: Lógica no cliente e interatividade das páginas.

## Como Executar o Projeto

Como o projeto é composto por arquivos estáticos, não é necessária a instalação de dependências complexas ou servidores de aplicação.

### Opção 1: Diretamente no Navegador
1. Faça o clone ou download deste repositório:
   ```bash
   git clone https://github.com/brenocad77/projeto_codelab.git
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `main.html` em qualquer navegador web de sua preferência (Chrome, Firefox, Edge, Safari).

### Opção 2: Servidor Local (Live Server)
Caso utilize o **VS Code**, é recomendável utilizar a extensão **Live Server**:
1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito sobre `main.html` e selecione **"Open with Live Server"**.

### Opção 3: Link de acesso direto pelo git
1. Abra o link no seu navegador:
   ```bash
    https://brenocad77.github.io/projeto_codelab/main.html   
   ```
